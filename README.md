# Chapter 6: Making Decisions — Interactive Practice

Interactive review for Chapter 6 Computer Science Foundations.

## Skills practiced
- Boolean values and logical expressions
- Comparison operators (`>`, `<`, `>=`, `<=`, `==`, `!=`)
- `if`, `elif`, and `else`
- Assignment (`=`) vs comparison (`==`)
- Logical operators: `and`, `or`, `not`
- Complex expressions and parentheses

## Student behavior
- Correct answers are marked complete automatically.
- Incorrect answers remain open so students can retry.
- Progress updates after each correct response.
- The practice is complete after all 10 questions are answered correctly.
